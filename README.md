Athena is a local AI desktop assistant I'm building to explore how a personal AI can work directly on a computer.

STATUS
Currently under development
Athena is still being built, so it isn't fully set up to run on other devices yet.

BUILT WITH
-Python
-Ollama
-Gemma 3 4B
-A modular Python architecture

ABOUT THIS PROJECT
This repository contains the ongoing development of Project Athena. The goal is to gradually turn it into a capable, local desktop assistant while keeping the system modular, lightweight, and easy to develop.
More features and improvements will be added as development continues.
